# 写真の置き場所

撮った写真・スクショを、**番号のついたフォルダにそのまま入れるだけ**でOKです。

## やること

1. 該当するフォルダを開く
2. 写真をドラッグ＆ドロップ
3. Claudeに「写真入れた」と伝える

以上です。

## やらなくていいこと

- **ファイル名の変更は不要**（`IMG_1234.jpg` のままでOK）
- **リサイズ・圧縮は不要**（こちらでWebP変換します）
- **枚数を揃える必要なし**（1枚でも入れてくれれば使います）
- **全フォルダ埋める必要なし**（撮れたものだけで進めます）

## ⚠️ 撮影時の注意（重要）

### 写り込ませないもの
- **他人の顔**
- **車のナンバープレート**
- **表札・部屋番号**
- **他人のレシートや書類**

### スクショで必ず隠すもの
- **口座残高・資産額**
- **氏名・住所・電話番号**
- **カード番号・口座番号**
- **メールアドレス**

隠し忘れがあってもこちらで確認しますが、**撮る時点で写さないのが一番安全**です。

### 撮影マナー
- 店舗内は、店員さんに一言断るか、外観・自分が買ったものを中心に
- **銭湯・温泉の脱衣所と浴室は絶対に撮らない**（記事があっても外観と料金表のみ）
- 免許センター等の公共施設は、掲示物や案内図が中心。窓口の人が写らないように

## このフォルダについて

ここは**作業用の一時置き場**です。Gitには入りません（`.gitignore`済み）。

Claudeが以下を行ってから、正式な場所（`static/images/articles/`）に配置します。

1. 個人情報の写り込みチェック
2. リサイズ・WebP変換（表示速度対策）
3. 記事の適切な位置に挿入
4. 英語のalt属性を記述
