# 写真・スクショ 優先撮影リスト（2026-08-14）

## なぜやるか

AdSenseが「有用性の低いコンテンツ」で審査落ちしている。原因の最有力候補は**サイトに画像が1枚もないこと**。

- 記事内の画像：**0本**（275記事すべて）
- 実在する画像ファイル：favicon と logo の**2つだけ**
- カバー画像：270記事が**6種類のSVGを使い回し**（daily-life だけで115記事が同一画像）

「日本での生活ガイド」というテーマで写真ゼロは、独自性の証拠がない状態。ここを埋めるのが最優先。

## 進め方の原則

- **全記事はやらない。** まず下記の優先20本だけ。
- **1記事に3〜5枚**あれば十分。
- **スマホで撮ったもので十分。** プロ品質は不要。むしろ現地の生々しさが価値。
- 撮影したら `static/images/articles/<記事slug>/` に置く。
- **人物の顔・ナンバープレート・表札・他人の個人情報が写り込まないよう注意。**
- 店舗内での撮影は、店員さんに一言断るか、外観・自分が買ったものを中心に。

# 撮影後の作業（Claude側で対応）

1. `static/images/articles/<slug>/` に配置
2. 各記事の適切な位置にキャプション付きで挿入
3. **alt属性を英語で記述**（SEOとアクセシビリティ、AdSense審査にも効く）
4. WebP変換・リサイズ（表示速度対策）
5. 使い回しSVGカバーを、その記事の実写に差し替え
6. Hugoビルド確認 → デプロイ
7. **AdSense再審査を申請**

# 現実的な見通し

- **AdSense再審査は何度でも出せる。** ただし何も変えずに出しても結果は同じ。
- 【A】のスクショ10本＋【B】の近所撮影だけでも、サイトの見え方は大きく変わる。
- **再審査に必ず通る保証はない。** Googleは理由の詳細を開示しない。ただし現状は「画像ゼロ」という明確な弱点があり、ここを埋めずに再申請するのは筋が悪い。
- 画像は**AdSenseだけでなく、検索順位・滞在時間・被リンク獲得（xyzAsia寄稿は写真5枚必須）にも同時に効く。** 一石三鳥の投資。
